# 메이플 보스노트

메이플스토리 주간 보스 진행과 드랍템 분배를 기록하는 개인용 PWA. 서버 없이 브라우저에서만 돈다.

## 쓰는 법

1. 아래 주소를 폰이나 PC 브라우저로 연다
2. 설정 탭에서 [넥슨 오픈API](https://openapi.nexon.com/ko/game/maplestory/) 키를 발급받아 입력한다
3. 캐릭터 탭에서 관리할 캐릭터와 보스를 고른다

폰에서는 브라우저 메뉴의 **홈 화면에 추가**를 누르면 앱처럼 설치된다.

## 데이터

모든 데이터(API 키 포함)는 **브라우저 localStorage에만** 저장된다. 서버로 전송되지 않고,
기기 간에 동기화되지 않는다. 폰과 PC는 각각 따로 설정해야 한다.

## 파일

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 구조 + 스타일 |
| `app.js` | 전체 로직 |
| `sw.js` | 서비스워커 (오프라인 캐시) |
| `manifest.webmanifest` | PWA 설치 정보 |

코드를 고치면 `sw.js`의 `CACHE_VERSION`을 반드시 올린다. 안 올리면 기기에 옛날 화면이 남는다.
